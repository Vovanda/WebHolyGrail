# Доступ: потоки

> Последовательности, которыми живёт модель из [`41-access.md`](41-access.md).
> Правила там, здесь - порядок шагов.

Шесть последовательностей, которыми модель живёт. Читаются сверху вниз: слева люди,
правее то, что решает.

### Просмотр закрытой записи

Проверка в два шага и в этом порядке: жив ли доступ, и только потом смотрим право.

```mermaid
sequenceDiagram
    autonumber
    actor Зритель
    participant П as Плеер
    participant Ключ as Выдача ключа
    participant Д as Доступ
    participant Пр as Право

    Note over Зритель,Пр: Просмотр закрытой записи
    Зритель->>П: открыл страницу
    П->>Ключ: ключ к записи, период N
    Ключ->>Ключ: токен читается, маркер посетителя известен
    Ключ->>Д: какие доступы покрывают запись
    Д-->>Ключ: свои записи и свои подборки
    Ключ->>Д: жив ли доступ, отсечка
    alt отсечка прошла
        Ключ-->>П: 403 нужен доступ
    else доступ жив
        Ключ->>Пр: есть право на этот доступ у маркера
        Пр-->>Ключ: срок и остаток просмотров
        alt право живо
            Ключ-->>П: 200, ключ 16 байт
        else истекло или исчерпано
            Ключ-->>П: 403 нужен доступ
        end
    end
```

### Активация кода

Одна на оба вида: различается только то, откуда пришло значение - из формы
на странице или из адреса приглашения.

```mermaid
sequenceDiagram
    autonumber
    actor Зритель
    participant Ф as Форма кода или адрес приглашения
    participant А as Активация
    participant Код
    participant Д as Доступ
    participant Пр as Право

    Note over Зритель,Пр: Активация - одна на оба вида кода
    Зритель->>Ф: ввёл диктуемый код либо перешёл по присланному
    Ф->>А: значение кода
    А->>Код: найти по значению
    Код-->>А: доступ, срок, предел срабатываний, отзыв, что даёт праву
    alt отозван, истёк или исчерпан
        А-->>Зритель: код не сработал
    else годен
        А->>Код: срабатывание засчитано
        А->>Д: доступ существует
        А->>Пр: завести право на маркер посетителя
        Note over Пр: свой срок и свой счёт просмотров - из условий кода
        Пр-->>А: заведено или продлено
        А-->>Зритель: открыто, состав доступа
    end
```

### Приглашение ссылкой

Ссылка ведёт к тому же доступу, что и код, но это своя сущность: адрес длинный
и машинный, срок обязателен, отзывают её галкой, не дожидаясь срока.

```mermaid
sequenceDiagram
    autonumber
    actor Владелец
    actor Зритель
    participant Д as Доступ
    participant С as Ссылка
    participant П as Приём ссылки
    participant Пр as Право

    Note over Владелец,Пр: Приглашение ссылкой
    Владелец->>Д: выбрал доступ
    Владелец->>С: выдать ссылку, срок обязателен
    С-->>Владелец: адрес приглашения
    Владелец-->>Зритель: прислал адрес
    Зритель->>П: открыл адрес приглашения
    П->>С: найти по адресу
    С-->>П: доступ, срок, предел, отзыв
    alt отозвана, истекла или исчерпана
        П-->>Зритель: приглашение больше не действует
    else годна
        П->>С: срабатывание засчитано
        П->>Пр: завести право на маркер посетителя
        Пр-->>П: заведено
        П-->>Зритель: переход на запись, она уже открыта
    end
```

### Выдача владельцем напрямую

Упирается в то, чем назвать адресата: маркер посетителя знает только его браузер.

```mermaid
sequenceDiagram
    autonumber
    actor Владелец
    actor Зритель
    participant Д as Доступ
    participant Пр as Право
    participant Код

    Note over Владелец,Код: Выдача владельцем напрямую
    Владелец->>Д: выбрал доступ
    Владелец->>Владелец: чем назвать адресата?
    alt у зрителя есть учётная запись
        Note over Владелец,Пр: в шаблоне этого нет - регистрации зрителей не существует
        Владелец->>Пр: завести право на учётную запись
        Пр-->>Владелец: заведено
        Зритель->>Пр: открывает запись
        Пр-->>Зритель: право найдено по учётной записи
    else назвать нечем
        Note over Владелец,Код: маркер посетителя знает только браузер зрителя
        Владелец->>Код: напечатать код от доступа
        opt владелец знает телефон или почту
            Владелец->>Код: приписать контакт к коду
        end
        Код-->>Владелец: значение кода
        Владелец-->>Зритель: продиктовал или прислал
        Зритель->>Код: активировал
        opt зритель оставил телефон или почту
            Зритель->>Код: контакт при активации
        end
        Код->>Пр: завести право на маркер посетителя
        Note over Пр: контакт, если он был, ложится рядом с маркером
        Пр-->>Зритель: открыто
    end
```

### Счёт просмотров

Просмотр - это первое взятие ключа к записи в пределах окна, а не каждый запрос:
ключ спрашивают на каждый отрезок потока.

```mermaid
sequenceDiagram
    autonumber
    actor Зритель
    participant Ключ as Выдача ключа
    participant Сч as Счёт ключей
    participant Пр as Право

    Note over Зритель,Пр: Что считается просмотром
    Зритель->>Ключ: ключ, отрезок 1
    Ключ->>Сч: брал ли он ключ к этой записи в этом окне
    Сч-->>Ключ: нет
    Ключ->>Пр: живо ли право
    Пр-->>Ключ: просмотров 2 из 3
    Ключ->>Пр: засчитать просмотр
    Ключ->>Сч: отметить запись и время
    Ключ-->>Зритель: 200, ключ
    Зритель->>Ключ: ключ, отрезки 2 и дальше
    Ключ->>Сч: брал ли в этом окне
    Сч-->>Ключ: да, окно идёт
    Ключ-->>Зритель: 200, ключ, счёт не тронут
    Note over Сч: окно кончилось - следующее взятие будет новым просмотром
    Зритель->>Ключ: вернулся назавтра
    Ключ->>Сч: брал ли в этом окне
    Сч-->>Ключ: нет
    Ключ->>Пр: живо ли право
    Пр-->>Ключ: предел выбран
    Ключ-->>Зритель: 403 нужен доступ
```

### Отзыв

Разом - датой отсечки у доступа; поштучно - снятием одного права.

```mermaid
sequenceDiagram
    autonumber
    actor Владелец
    actor Аня
    actor Борис
    participant Д as Доступ
    participant Ключ as Выдача ключа

    Note over Владелец,Ключ: Отзыв разом
    Владелец->>Д: отсечка = сегодня
    Аня->>Ключ: ключ к записи
    Ключ->>Д: жив ли доступ
    Д-->>Ключ: закрыт
    Ключ-->>Аня: 403 нужен доступ
    Борис->>Ключ: ключ к записи
    Ключ->>Д: жив ли доступ
    Д-->>Ключ: закрыт
    Ключ-->>Борис: 403 нужен доступ
    Note over Д: права целы, вернул дату - просмотр вернулся
```

```mermaid
sequenceDiagram
    autonumber
    actor Владелец
    actor Аня
    actor Борис
    participant Пр as Право
    participant Ключ as Выдача ключа

    Note over Владелец,Ключ: Отзыв поштучно
    Владелец->>Пр: снять право Ани
    Аня->>Ключ: ключ к записи
    Ключ->>Пр: живо ли право
    Пр-->>Ключ: права нет
    Ключ-->>Аня: 403 нужен доступ
    Борис->>Ключ: ключ к записи
    Ключ->>Пр: живо ли право
    Пр-->>Ключ: живо
    Ключ-->>Борис: 200, ключ
    Note over Владелец,Ключ: доступ цел, закрылся один держатель
```
