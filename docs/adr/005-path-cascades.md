# ADR-005: Материализованный путь и каскады

**Статус:** принято
**Дата решения:** 2026-10-23
**Приоритет:** высокий для сервиса и перепродажи
**Цена отката:** путь в каждой записи вместо ссылки на каскад - перестройка иерархии превращается в миграцию всех таблиц.

## Контекст

1. Ветку и предков нужно выбирать одним запросом, без рекурсии, а дерево - получать
   отсортированным.
2. Иерархию перестраивают: клиент уходит к другому партнёру, ветку передают.
3. Денежная запись, ссылающаяся на изменяемую структуру, при перестройке меняет
   владельца задним числом.
4. У арендатора несколько виртуальных счетов; деньги на каждом уровне идут с одного из
   них.

## Решение

Мы будем:

- Хранить путь массивом целых от корня: ветка и предки - одним запросом, `ORDER BY
path` - дерево по порядку, уровень - длина пути. Путь вычисляет база из родителя,
  руками он не пишется.
- Хранить путь в версии каскада, а не у арендатора: арендатор постоянен, его место в
  дереве - действующая версия каскада.
- Вести два каскада: арендаторов (кто чей) и балансов (с какого счёта на каждом уровне
  идут деньги; по умолчанию - основной счёт уровня).
- Ссылаться из записей на каскад: перестройка иерархии - несколько правок каскадов.
- Менять каскад только новой версией с датой; денежная запись ссылается на версию, по
  которой прошла.
- Хранить путь в Postgres как `bigint[]` с GIN и операторами `@>`/`<@`; в SQLite - как
  текст из сегментов фиксированной ширины с ведущими нулями, который сортируется так же
  ([ADR-001](001-databases.md)).

## Альтернативы

- Ссылка на родителя и рекурсия - ни сортировки, ни выборки ветки по индексу.
- Таблица замыкания - вторая таблица, которую держать в согласии с деревом.
- Путь строкой из глобальных id - теряет числа, сортировку и компактность.
- Путь в каждой записи - перестройка переписывает таблицы и историю.

## Последствия

- Хорошее: перестройка без миграции данных; история денег неизменна.
- Плохое: таблица версий каскадов растёт с каждой перестройкой.

## Соблюдение

Путь вне версии каскада, правка версии вместо новой и денежная запись без ссылки на
версию - блокер на ревью.
