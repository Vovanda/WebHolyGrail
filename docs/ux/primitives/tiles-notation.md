# Нотация раскладки плиток

> Правила записи целиком. Про сам примитив и зачем он - [сетка плиток](tiles.md).
> Разбор живёт в `contracts/src/grid-areas.ts`, им пользуется и сайт, и проверка
> в админке.

## Из чего состоит запись

```
a b c e : a b d d
```

**Ячейка** - одно место в сетке, названо одним знаком. **Ряд** - несколько ячеек,
разделённых пробелами. Ряды разделяются двоеточием.

## Знаки

| Знак               | Значит                 | Пример         |
| ------------------ | ---------------------- | -------------- |
| буква              | карточка               | `a b c`        |
| число перед знаком | повтор, он же ширина   | `3a` = `a a a` |
| `.`                | пустое место           | `a . b`        |
| `-` перед буквой   | карточку не показывать | `-f`           |
| `:`                | конец ряда             | `a b : c d`    |

**Имя - один знак.** Так слитная запись читается однозначно: `3a` это три карточки
`a`, а не число и слово. Больше пятидесяти двух областей руками никто не пишет,
а досчитанным карточкам имя и не нужно - у них есть номер.

**Порядок имён и есть порядок карточек.** Первое по алфавиту имя означает первую
карточку блока, второе - вторую. Отсюда перестановка: в записи `e a b c` первой
показывается пятая карточка.

## Размер

Размер не задают отдельно - он читается из числа занятых ячеек:

```
a b c e
a b d d
```

`a` и `b` стоят в двух рядах - тянутся на два ряда. `d` занимает две ячейки в ряду -
на две колонки. Область каждого имени обязана быть цельным прямоугольником:
`a b : b a` описывает фигуру, которой не бывает.

## Пустота

Ряд короче соседних встаёт по середине - но только если владелец не сказал иначе.
Как только в ряду появилась точка, ряд считается разложенным вручную, и центрирование
выключается.

| Запись            | Что выходит                                            |
| ----------------- | ------------------------------------------------------ |
| `a b : c : d e`   | `c` по центру своей строки                             |
| `a b : . c : d e` | `c` справа: место слева занято                         |
| `a b : . : c d`   | пустая строка между рядами                             |
| `a b : : c d`     | ничего: ряд без ячеек схлопывается                     |
| `. . . .`         | пустая строка; ширину сетки такой ряд не задаёт        |
| `. a . .`         | здесь есть имя - ряд считается, сетка в четыре колонки |

## Выключенная карточка

Минус убирает карточку совсем: места не занимает, авто-подбор её не берёт, соседи
сдвигаются. Писать можно где угодно, удобнее хвостом: `a b c : d e : -f -g`.
Ряд, где всё выключено, схлопывается. `-3f` не принимается: повтор описывает размер,
а у невидимой карточки размера нет.

## Чего в записи нет

Запись описывает начало сетки, а не всю её. Остальные карточки досчитываются сами -
сбалансированными рядами, тем же правилом, что и сетка без записи вовсе. Добавили
карточку - строку править не надо.

Досчитанные карточки имени не получают, только номер: алфавит нужен там, где человек
называет области руками, и авто-раскладка от него не зависит вовсе.

## В поле пишет только человек

Фигура считается при показе и в базу не возвращается. Ни посчитанное, ни «для
наглядности» - поле остаётся ровно таким, каким его оставил владелец.

Иначе вышло бы худшее: поле однажды заполнилось бы само, человек увидел бы там
строку, которую не писал, поправил её - и с этого момента фигура перестала бы
пересчитываться при добавлении карточек. Пустое поле означает «считай сам»,
и оно обязано оставаться пустым, пока человек сам не напишет.

## Три записи по ширинам окна

Фигура задаётся отдельно для трёх ширин: **большой экран** от 1024 точек, **средний**
от 768 до 1023, **малый** до 767. Названы по ширине окна, а не по устройству: окно
на большом мониторе бывает узким, а планшет держат и поперёк.

Каждая живёт сама по себе: незаполненная не наследуется, а считается заново под свою
вместимость. Иначе фигура из четырёх колонок приехала бы на малый экран и раздавила
карточки.

## Как читается запись

Разбор посимвольный, состояний немного. Таблица полна по построению: в каждой клетке
либо переход, либо названная ошибка.

| Состояние \ знак  | буква              | цифра                             | `.`            | `-`      | пробел                  | `:`        | прочее |
| ----------------- | ------------------ | --------------------------------- | -------------- | -------- | ----------------------- | ---------- | ------ |
| **начало ячейки** | ячейка готова      | копим повтор                      | пустое место   | ждём имя | пропуск                 | конец ряда | ошибка |
| **копим повтор**  | столько ячеек      | копим дальше                      | столько пустых | ошибка   | ошибка: число без имени | ошибка     | ошибка |
| **ждём имя**      | карточка выключена | ошибка: у выключенной размера нет | ошибка         | ошибка   | ошибка                  | ошибка     | ошибка |

Ошибка называет ячейку и причину, а не «запись не читается»: `«3» - число ничего
не называет`, `«-3f» - у выключенной карточки размера нет`, `«!» - имя пишется буквой`.

## Когда запись не принимается

Целиком, с сообщением в админке:

- посторонний знак;
- число без имени;
- минус с повтором;
- имя не складывается в прямоугольник.

Молча уронить фигуру хуже, чем не взять её: человек хотя бы видит, что раскладка
не применилась, и знает почему.
