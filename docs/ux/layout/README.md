# Раскладка сайта

Каркас сайта задаётся описанием панелей в `SiteSettings.layout`, а не вёрсткой в шаблоне
страницы. Один компонент `SiteLayout` разворачивает любое такое описание: смена описания
меняет каркас всего сайта, страничные компоненты не трогаются.

Контракт — `contracts/src/layout.ts` (`SiteLayoutConfig`, `PanelConfig`). Панели описаны
отдельно: [`panels.md`](panels.md).

## Слоты

| Слот      | Что кладут                               | Как разворачивается     | Сколько панелей |
| --------- | ---------------------------------------- | ----------------------- | --------------- |
| `top`     | шапка, объявление над ней                | колонкой над содержимым | сколько угодно  |
| `bottom`  | подвал, нижняя панель телефона           | колонкой под содержимым | сколько угодно  |
| `center`  | вывод страницы, постоянные блоки         | основной поток          | минимум один    |
| `left`    | навигация, разделы каталога, оглавление  | по режиму панели        | сколько угодно  |
| `right`   | список серии, корзина, помощь по разделу | симметрично левому      | сколько угодно  |
| `overlay` | поиск во весь экран, общий хост окон     | поверх всего            | сколько угодно  |

Слотов ровно шесть, других не бывает. Панелей в одном слоте — сколько угодно: движок
перебирает их все, ограничения «одна панель слева» нет. Несколько панелей в одном слоте
рисуются вкладками, подпись и значок берутся из `meta`.

## Описание раскладки

| Поле            | Тип                          | Что задаёт                         | Умолчание      |
| --------------- | ---------------------------- | ---------------------------------- | -------------- |
| `panels`        | `PanelConfig[]`              | все панели сайта                   | обязательное   |
| `grid.template` | `'classic-site' \| 'custom'` | готовая сетка слотов или своя      | `classic-site` |
| `grid.rows`     | `string`                     | строки сетки, только при `custom`  | —              |
| `grid.columns`  | `string`                     | колонки сетки, только при `custom` | —              |
| `grid.areas`    | `string[]`                   | области сетки, только при `custom` | —              |

Минимальное описание — одна панель в `center`: без неё страницам негде выводиться.

```jsonc
{
  "panels": [
    {
      "id": "header",
      "slot": "top",
      "content": { "kind": "block", "node": { "type": "site-header" } },
    },
    {
      "id": "page",
      "slot": "center",
      "content": { "kind": "block", "node": { "type": "page-outlet" } },
    },
    {
      "id": "footer",
      "slot": "bottom",
      "content": { "kind": "block", "node": { "type": "site-footer" } },
    },
  ],
}
```

## Две оси ширины

Ширина панелей и ширина содержимого — независимы.

| Ось                | Чем задаётся          | На что влияет                          |
| ------------------ | --------------------- | -------------------------------------- |
| Ширина панели      | `size` у самой панели | сколько места занимает слот            |
| Ширина содержимого | блок внутри `center`  | как широко идёт текст и блоки страницы |

Панель, ужавшая содержимое, не меняет его внутреннюю меру: узкий текст остаётся узким,
широкая витрина — широкой.

## Что происходит на узком экране

Поведение задаётся у каждой панели полем `mobile`, значения — в [`panels.md`](panels.md).
Значения описывают только узкий экран: на широком боковая панель стоит в раскладке
и ужимает содержимое.

## Ограничения

- Слот `center` обязателен; без панели в нём страницы выводить некуда.
- Слотов шесть и список закрыт: свой слот не заводится, вместо этого берётся ближайший
  подходящий.
- Содержимое панели сериализуемо: в описание кладётся блок или адрес маршрута, но не
  функция и не готовый узел разметки.
- Маршрут в панели (`kind: 'route'`) предназначен для панелей инструментов; публичная
  навигация сайта — обычные страницы, иначе посетитель теряет адрес.

## Где применяется

- `src/client/src/layouts/site-layout/` — разворачивание описания, видимость и адресные
  маски панелей, реестр блоков.
- `contracts/src/layout.ts` — сам контракт.
- Проверки: `panel-routes.test.ts`, `panel-visibility.test.ts`, `SiteLayout.test.tsx`.

## Почему так

Раскладка вынесена в описание, потому что второй сайт на том же движке приходит с другим
каркасом, а страницы у него те же. Пока каркас живёт в вёрстке, каждый такой сайт требует
правки страничных компонентов — и они расходятся между сайтами навсегда.

Слоты фиксированы, чтобы описание оставалось читаемым и переносимым: произвольная сетка
даёт бесконечную свободу и вместе с ней невозможность перенести настройку на соседний
сайт. Своя сетка остаётся доступной через `grid.template: 'custom'` для случаев, где
шести слотов действительно мало.

Подробности контрактной границы между фронтом и админкой — `docs/whg/30-philosophy.md`
(R3, R4, R5) и `docs/whg/32-structure.md`.
