# Панели

Панель — единица раскладки. Шапка, подвал, навигация, список серии, корзина, поиск
во весь экран — всё это панели в одном из шести слотов, описанные одинаково.

Контракт — `PanelConfig` в `contracts/src/layout.ts`. Слоты и общая картина —
[`README.md`](README.md).

## Свойства

| Поле          | Тип                                                     | Что задаёт                                       | Умолчание         |
| ------------- | ------------------------------------------------------- | ------------------------------------------------ | ----------------- |
| `id`          | `string`                                                | имя панели, по нему же различаются вкладки       | обязательное      |
| `slot`        | `top \| bottom \| left \| right \| center \| overlay`   | где панель живёт                                 | обязательное      |
| `content`     | `{ kind: 'block', node }` или `{ kind: 'route', path }` | что показать внутри                              | обязательное      |
| `size`        | `string \| number`                                      | ширина для боковых, высота для верхней и нижней  | по содержимому    |
| `visibility`  | `always \| desktop \| mobile`                           | на каких экранах панель существует               | `always`          |
| `mobile`      | `push \| overlay \| drawer-bottom \| hidden`            | что делает на узком экране                       | обычная раскладка |
| `routes`      | `string[]`                                              | адреса, где панель показывается                  | везде             |
| `collapsible` | `boolean`                                               | можно ли свернуть                                | `false`           |
| `resizable`   | `boolean`                                               | можно ли тянуть границу                          | `false`           |
| `defaultOpen` | `boolean`                                               | открыта ли сразу                                 | `false`           |
| `meta.title`  | `string`                                                | подпись вкладки, когда панелей в слоте несколько | —                 |
| `meta.icon`   | `string`                                                | значок вкладки                                   | —                 |

## Что кладут внутрь

Содержимое панели — сериализуемое описание, не готовый узел разметки. Отсюда два вида.

| Вид                       | Что это                                            | Когда берут                                              |
| ------------------------- | -------------------------------------------------- | -------------------------------------------------------- |
| `{ kind: 'block', node }` | обычный блок сайта, тот же, что кладут на страницу | почти всегда: шапка, подвал, меню, список серии, фильтры |
| `{ kind: 'route', path }` | вывод страничного маршрута внутри панели           | панели инструментов: панель управления, рабочее место    |

В панель кладётся **любой** блок из реестра — своих ограничений у панели нет. Блок
получает те же настройки, что и на странице, и правится из админки так же.

Маршрут в панели предназначен для инструментов. Публичная навигация делается обычными
страницами: посетитель должен видеть адрес того, что читает.

## Несколько панелей в одном слоте

Ограничения «одна панель слева» нет: в слот кладётся сколько угодно панелей, движок
перебирает все. Когда их больше одной, слот показывает вкладки — подпись и значок берутся
из `meta`.

```jsonc
"panels": [
  { "id": "toc",   "slot": "right", "meta": { "title": "Оглавление" },  "content": { "kind": "block", "node": { "type": "article-toc" } } },
  { "id": "serial","slot": "right", "meta": { "title": "Серия" },       "content": { "kind": "block", "node": { "type": "video-set-list" } } }
]
```

## Узкий экран

| Значение `mobile` | Что происходит                                | Кто рисует                    |
| ----------------- | --------------------------------------------- | ----------------------------- |
| `push`            | панель выезжает и отодвигает страницу целиком | движок, через примитив панели |
| `overlay`         | панель ложится поверх страницы                | сам блок                      |
| `drawer-bottom`   | полка снизу                                   | сам блок                      |
| `hidden`          | панели на узком экране нет                    | —                             |

Значения описывают только узкий экран: на широком боковая панель стоит в раскладке
и ужимает содержимое.

Выбор между `push` и `overlay` смысловой. `push` — часть той же работы, человек
переключается туда-обратно и хочет видеть, что страница на месте: список серии,
оглавление, фильтры. `overlay` — действие, которое прерывает: меню сайта, поиск.

`push` двигает весь каркас вместе с шапкой. Двигать одну середину нельзя: панель ляжет
поверх шапки, и выйдет сдвинуто и перекрыто разом.

## Адресные маски

Раскладка одна на весь сайт, поэтому без масок панель попадает на каждую страницу.

```jsonc
"routes": ["/video", "/blog/*"]
```

| Маска     | Совпадает                          | Не совпадает     |
| --------- | ---------------------------------- | ---------------- |
| `/video`  | ровно `/video`                     | `/video/123`     |
| `/blog/*` | `/blog/post`, `/blog/post/comment` | `/blog`          |
| `/@*/p/*` | `/@author/p/slug`                  | `/@author/about` |

Звёздочка на месте кусочка пути означает любой один, звёздочка в конце — «и всё, что
дальше». Пусто или поле не задано — панель показывается везде.

Проверки масок — `src/client/src/layouts/site-layout/panel-routes.test.ts`.

## Как панель появляется

Панель лежит слоем ниже содержимого и выходит из-под его края: у правой стороны движение
идёт слева направо, у левой зеркально.

Порядок слоёв: средняя секция выше панели — из-под её края панель и выходит; шапка идёт
по ширине средней секции и лежит ещё выше, а её пустые продолжения по краям — ниже панели,
поэтому приехавшая панель их закрывает; подвал целиком выше панели, иначе она ложилась бы
на него концом.

Сколько уступает страница: `ширина панели − свободное поле сбоку`, не меньше нуля.
На широком экране это ноль — уступать нечего.

## Ограничения

- Содержимое сериализуемо: функции и готовые узлы разметки в описание не кладутся.
- Слот `center` не поддерживает `mobile`: содержимое страницы никуда не уезжает.
- Панель в `overlay`-слоте не участвует в раскладке и не ужимает содержимое.
- Порядок вкладок в слоте — порядок панелей в описании.
