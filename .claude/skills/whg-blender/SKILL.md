# Skill: whg-blender

> Генерация хороша для фото, Blender - для всего, где важны форма, ракурс и физика света.
> Одна сцена даёт сколько угодно стилей и обе темы без расхождения в пикселях.

## Когда триггерить

- Картинке нужна точная геометрия, перспектива или раскладка по сетке
- Нужен материал с физикой: стекло, плёнка, бетон, металл, свечение
- Нужна тёмная пара, совпадающая со светлой пиксель в пиксель
- Новый материал, деформация или свет - перед первой строкой

## Запуск

Portable-сборка, Cycles на GPU (OptiX), всё из консоли:
`blender -b -P <скрипт> -- <аргументы>`. Сцена собирается скриптом с нуля
(`read_factory_settings(use_empty=True)`), руками в интерфейсе ничего не правится: иначе
результат не повторить. Черновики на 32-64 сэмплах, финал на 256; размер - через
`resolution_percentage`, а не через камеру.

Каждый параметр, который приходится подбирать на глаз, выносится в переменную окружения
со значением по умолчанию. Подобранное значение потом становится значением по умолчанию,
и финал повторяется одной командой.

## Сцена и камера по фото

Сцена строится на якорях: у каждого объекта центр, глубина, ширина, высота в метрах.
Якоря снимаются с эталонного фото по пикселям. Глубина берётся по линии земли:
`z = f · h_cam / (y_base − y_horizon)`, остальные размеры - через ту же глубину.

Камера - тот же фокус в пикселях: `lens = 36 · f / W` при `sensor_fit = HORIZONTAL`,
точка схода - через `shift_x` и `shift_y`, взгляд горизонтальный. Прежде чем строить стиль,
положи кубы по якорям поверх фото: если не совпало, стиль не спасёт.

## Свет и фон

Фон кадра равен фону страницы, на которую ляжет картинка, иначе на стыке будет шов.

- **Светлая тема.** View transform `Standard`, не `AgX`: AgX уводит белый в серый. Мир белый,
  сила около 1.6, пол белый матовый - шва между полом и небом нет. Такой мир пережигает
  лицевые грани непрозрачных материалов. Для них свет мира ниже, а белый фон и мягкая тень
  делаются ловцом теней (`is_shadow_catcher`, кадр с альфой) и наложением на белый
  с приглушённой тенью.
- **Тёмная тема.** Камера видит тёмный фон (мир смешан по `Light Path - Is Camera Ray`),
  рассеянного света нет. Пол - эмиссия цвета фона без освещения: ни засветки, ни отражений.
- **Ореол.** `Glare / Fog Glow` в компоновщике со слабым смешиванием (`mix` около -0.7).

## Стекло

- **Цветная тень.** Для теневых лучей (`Is Shadow Ray`) материал - прозрачный BSDF цвета
  стекла, иначе Cycles кладёт от стекла серую тень.
- **Глубина слоёв.** `Volume Absorption` цвета стекла в выход `Volume`: каждый слой поверх
  другого темнит. Толстые объекты поглощение красит в чёрный, им его не дают.
- **Светлые цвета.** Жёлтый, рыжий, золотой в светлом стекле выгорают, им нужна своя,
  заметно более тёмная база.
- **Свечение в темноте.** Торцевая подсветка, как у акриловой вывески: эмиссия только по ободу
  (`Layer Weight - Facing` через `Map Range` от 0.55, сила около 6), тело - прозрачное стекло
  с поглощением. Задние слои видны сквозь передние и гаснут.

Любой свет, который ложится на все слои разом, - эмиссия толщи, светильники внутри,
прожектор от камеры - складывается по слоям в молочную заливку: стекло белеет и теряет
глубину. Светильники сверху прозрачное стекло почти не ловит.

## Плёнка

- **Тон.** Целлофан не бесцветный: прозрачный BSDF чуть синеватый (около `0.93, 0.96, 1.0`).
  Темнее - наложения листов темнят и картинка грязнеет.
- **Рисунок на плёнке.** Картинка с альфой в эмиссию, вне рисунка - прозрачность. Поля плёнки
  вокруг рисунка - через `Mapping` UV, а не растягиванием картинки.
- **Мятость.** Сетка, триангуляция, шум со скоростью изменения примерно на шаг сетки и плоское
  затенение: вершины уходят вразнобой, плёнка ломается гранями. Плавный шум даёт волну,
  а не мятость.
- **Рулоны и изгибы.** Задаются геометрией вершин: сечение листа - функция от места по ширине
  (волна, дуга, спираль рулона с сохранением длины дуги). `Simple Deform` с пределами гнёт
  не ту ось и рвёт лист; масштаб перед деформацией применяется к сетке, иначе изгиб считается
  в растянутом квадрате.
- **Рябь.** Преломление только у прозрачной части: IOR около 1.006 и мелкий шум в нормали.
  Преломление на гранях мятости даёт цветные крапинки.
- **Наложения.** Маска по лучам из камеры: луч через вершину листа и дальше; попал в другой
  лист - здесь сквозь лист видна чужая картинка. В маске - несколько мягких диагональных
  отсветов разной толщины, около 45% непрозрачности. Сплошная подложка убивает прозрачность,
  частая регулярная штриховка рябит.
- **Не пересекаться.** После расстановки листы расталкиваются по габаритам: дальний отъезжает
  вглубь, пока не разойдутся.

## Процедурные материалы

- **Бетон.** Шум Перлина (`Noise Texture`, FBM) в двух масштабах: крупный - пятна краски,
  мелкий - зерно, он же в `Bump`. Фотограмметрическая текстура - только тонким слоем в цвете:
  её рельеф с проекцией `Box` даёт швы тайлов.
- **Фотограмметрия.** Контраст цветовой карты несколько процентов, без растяжки вокруг среднего
  (`Map Range`) фактуры не видно. UV у текста нет - проекция `Box` по координатам объекта,
  тайл в метрах через масштаб объекта.
- **Полосы и штрихи.** Расположение задаётся явно (`|u + v − c| / ширина`), толщина гуляет
  по шуму. Узел `Wave` удобен, но регулярен: его полосы читаются как решётка.

## Узлы, на которых теряется время

- У `Mix` в Blender 4 по три входа `A` и `B` (число, вектор, цвет). По имени берётся числовой,
  цвет молча не доходит: цветовые - `inputs[6]`, `inputs[7]`, выход `outputs[2]`.
- Перевод строки в метке через Python пиши `chr(10)`: правка скриптом через heredoc
  превращает `\n` в настоящий перенос внутри строкового литерала.

## Тёмная пара обработкой

Когда сцену для тёмной темы не пересобрать светом, пара получается инверсией светлоты в Lab
с сохранением `a` и `b`: оттенки остаются, белое уходит в фон тёмной темы. Проверь контраст:
светлые бледные заливки после инверсии становятся тусклыми.

## Проверка

- Наложение на каркасы якорей той же камерой: лист, буква, куб на месте.
- Вид сверху ортографической камерой - контуры изгибов видны без перспективы.
- Крупный план участка, о котором спорят, а не только общий кадр.
