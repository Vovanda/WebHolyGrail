# Skill: whg-imagegen

> Картинка на сайте - это строка в серии, а не удачный кадр из интерфейса. Серию
> можно перегенерировать через год и получить те же пиксели.

## Когда триггерить

- Сайту нужны фоны, картинки карточек, иллюстрации разделов, варианты лого
- Серия начала расходиться по стилю
- Нужна тёмная версия готовой картинки
- Выбираешь или меняешь модель
- На машине ещё не было генерации - сперва `doctor`

## Сначала проверка

```bash
node .claude/skills/whg-imagegen/imagegen.mjs doctor [--host http://127.0.0.1:8188] [--models <диск или папка models>]
```

Проверка смотрит видеокарту, ComfyUI, нужные модели и место на диске. Итог:

- **ГОТОВО** (код 0) - работать;
- **МОЖНО ПОСТАВИТЬ** (код 2) - печатает, откуда взять ComfyUI и команды на
  каждую недостающую модель; ставить только с согласия владельца, это ~53 ГБ;
- **НЕ ПРИМЕНЯТЬ** (код 3) - нет видеокарты NVIDIA или места: навык на этой
  машине не используется, картинки берутся иначе.

Проверенный порог - 24 ГБ видеопамяти. Меньше проверка помечает как «не проверено»:
ComfyUI выгружает веса в память и, вероятно, справится медленнее, но это не
подтверждено.

## Модель и лицензия

Картинки идут на коммерческие сайты, поэтому лицензия проверяется до скачивания.

| Модель                                   | Лицензия                                                             | Для чего                                                   |
| ---------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------- |
| Qwen-Image-2512 (fp8, 20 ГБ)             | Apache 2.0                                                           | основная: точно держит промпт, латиница на картинке чистая |
| Qwen-Image-Edit-2511 (fp8mixed, 20 ГБ)   | Apache 2.0                                                           | правка готовой картинки: тёмная пара, убрать людей         |
| Qwen-Image-2512-Lightning 8 шагов (LoRA) | Apache 2.0                                                           | черновики: ~25 с вместо ~3 мин                             |
| Flux.1-dev                               | выходы коммерчески можно, обучать на них конкурирующую модель нельзя | быстрее в 8 раз, но хуже держит промпт                     |
| Qwen-Image 2.1, Ideogram 4               | только некоммерческие                                                | не брать                                                   |

Файлы - репаки Comfy-Org на Hugging Face (`Comfy-Org/Qwen-Image_ComfyUI`,
`Comfy-Org/Qwen-Image-Edit_ComfyUI`), параметры - из официальных шаблонов
ComfyUI (`comfyui_workflow_templates_json`), а не по памяти. На 24 ГБ видеопамяти
Qwen с энкодером целиком не помещается и подгружается по ходу - это нормально.

## Серия

Серия лежит в репозитории сайта: `design/images/<серия>/series.json`. Папка
`out/` в git не идёт - `.gitignore` сайта держит `design/images/**/out/`.

```json
{
  "name": "Карточки направлений",
  "engine": "qwen",
  "style": "Professional studio product photography, ... no text, no logos",
  "negative": "low quality, cluttered background, text, watermark",
  "items": [
    { "id": "hvac", "size": "4:3", "seed": 27202, "subject": "A modular air handling unit ..." },
    {
      "id": "hero-dark",
      "source": "out/qwen/hero.png",
      "seed": 101,
      "scale": true,
      "edit": "Dim the lighting ... Keep everything else exactly the same."
    }
  ]
}
```

- **Стиль пишется один раз** в `style` и приклеивается к `subject` скриптом. Дописать
  стиль руками в отдельный промпт - то, отчего серия расходится.
- **Seed у каждой картинки свой и записан.** Та же модель, та же версия ComfyUI,
  та же карта - попиксельно та же картинка (проверено: разница 0).
- **Промпт по-английски.** Русский текст на картинке ломают все модели - его
  накладывает вёрстка; латиница (название бренда) рисуется чисто.
- **Размер - родной для модели** (около 1,3 Мп: 1664×928, 1472×1104, 1328×1328).
  Меньший размер портит детали, а сайт всё равно отдаёт посетителю копию по месту.

## Скрипт

```bash
node .claude/skills/whg-imagegen/imagegen.mjs <путь>/series.json [--only id,id] [--draft] [--host ...]
```

Рядом с каждой картинкой ложится `<id>.json`: промпт, seed, размер, время и граф,
ушедший в ComfyUI. Черновой режим (`--draft`) - для перебора, полное качество -
для утверждённого.

## Порядок работы

1. Референс заказчика или ниши - смотреть глазами, брать стиль, а не снимки.
2. Серия якорей: 3-4 варианта одного промпта с разными seed.
3. Страница на утверждение (артефакт): пары рядом, спорное помечено.
4. Утверждённое - в серию как есть, остальное перерисовывается по замечаниям.
5. На сайт - только утверждённое, через API медиатеки.

### Минимум и логика

Заказчик-специалист видит незнание техпроцесса с первого взгляда, и сайт после
этого выглядит сгенерированным. Поэтому:

- **Один узнаваемый предмет или материал.** Не пирог в разрезе, не узел из пяти
  деталей: чем сложнее конструкция, тем выше шанс бреда. Рулоны мембраны
  вместо среза кровли, труба с одним краном вместо обвязки с насосом.
- **Без инструментов и составных приборов.** Модель склеивает их в несуществующие
  («фен с роликом», воронка, сросшаяся с рулоном).
- **В промпте прямо запрещать лишнее:** «Nothing else in the scene, no tools».
- **Каждую картинку смотреть крупно до показа**, а не миниатюрой: насос в оси трубы,
  трубки в никуда, комбинезон или брюки, порядок слоёв видны только в полный размер.
- Сомнительное, но утверждённое не заменять молча: дорисовать простой вариант
  рядом и показать.

## Тёмная пара

Тёмная версия делается **правкой светлой** через Edit-2511, а не отдельной
генерацией: новая генерация даёт другую комнату, и при смене темы картинка
«прыгает».

- В инструкции перечислять, что оставить как было (потолок, стены, ракурс), и
  одну вещь, которую поменять.
- `"scale": true` - правка идёт в размере, под который модель обучена. Без него, в
  исходных 1664×928, на стенах выходят радужные разводы.
- Результат в размере Kontext кадром чуть уже исходника; скрипт сам подгоняет его
  к кадру светлой (обрезка по центру до пропорции, масштаб до исходного размера).

Показать пару сайт может только там, где блок умеет менять картинку по теме.
Проверь это до генерации, иначе картинке нужна нейтральная подача на обе темы.

## Грабли

- Коннектор Google Диска загружает файл только base64 прямо в вызове - для
  картинок это не путь. Показ - страницей артефакта.
- Узел масштабирования из шаблона Edit меняет кадр - см. «Тёмная пара».
- Лого генерацией - только идеи. Итоговое лого рисуется в SVG.
